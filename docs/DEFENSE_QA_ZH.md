# 与本项目事实对应的10问答

1. **为什么不直接融合KF-GINS后验？** 后验含历史GNSS和共享IMU相关信息，高频注入会重复计数。本轮KF-GINS只作为独立B1。
2. **外层是否ESKF？** 不是。它是固定旋转下三维线性位置KF；原生KF-GINS才有21维误差状态。
3. **用了什么真值？** i2Nav MM/INS local NED参考共享AT128；第一个状态用于受控初始化，其余只由离线评价读取。不能称独立真值或无先验部署。
4. **GNSS差分是不是第二条量测？** 不是。短差分与原始锚只控制接入，每条GNSS ID最多一次KF更新。
5. **为什么窗口一致仍可能错？** 稳定偏移在短差分中相消；r02实际存在该失败，r03冻结过去锚作跨断点比较。
6. **锚能确定哪一传感器坏吗？** 不能。GNSS偏差与LIO漂移可观测等价；错误锚、过大接收机R、health回退都可能削弱保护。
7. **强对照给了多少调参机会？** 共同Q有限校准、4组NIS、4组Huber、12组固定恢复；共112个配置/场景组合。候选3轮各12主配置，统一正常代价上限，没有候选独享的大搜索。
8. **开发改善来自什么？** 双缓存目标收益22.80%/24.02%，无锚退到r02、无运动精确复现B6、时间资格较差，支持锚接入。去掉衰减略好，不能说衰减必需；非目标事件会退化。
9. **这些是独立、真实现场和在线结果吗？** building00是开发；parking00只有冻结后才开启。扰动是人工压力，两个building缓存不是独立路线。原生前端计时、缓存重放与现场在线延迟明确区分。
10. **创新与论文状态如何？** 一致性/滑窗/恢复调R已有先例；仅检验有限SPP位置接入应用增量，新颖性未证明。当前方法/实验稿是内部草稿，独立结果尚待完整评价，没有署名或正式投稿。

# 观测恢复机制：r01–r03 与实现归属

当前是已执行三轮方法说明，不是有效性或新颖性证明。building00为开发；parking00在科学冻结后已开启并完成。最终长等待强控制反证使本轮结论为NO_ADDITIONAL_GAIN。前端、初态、位置KF、Q/R、评价网格和21个固定事件跨方法相同。协议在候选性能前登记；最多3轮、每轮12主配置。

## 共同滤波与监测

FAST-LIO2提供局部位置/姿态，固定初始旋转A将增量转至NED，p⁻=p+AΔp_L。共同Q=diag(1,1,4)×(0.001Δt+0.001Δdistance)，单位分别m²/s与m²/m。当前天线量测模型z=p+R_NB l+v，杆臂FRD[0,-0.07,-0.365]m；只用当前原始F9P一次Joseph位置KF更新。Huber限2.5，原始接收机NED标准差下限[1,1,2]m。差分和锚仅作接入管理，不创建独立量测，不融合KF-GINS后验。

令a_L为独立LIO补偿到天线的NED位置。短时监测d=(z_t−z_old)−(a_L,t−a_L,old)。old来自过去W秒、容差0.5秒的连续GNSS；间隔>1.5秒清窗。工程分数d_xyᵀ(R_t,xy+R_old,xy+Q_interval I)⁻¹d_xy，并非独立、校准的卡方证据。

共同B6固定恢复规则：当前名义NIS>16.266236或GNSS间断>2秒后隔离至少2秒，接入后R倍率15→1在15秒内作有限平方衰减。候选继承该强策略，新增连续通过短时监测的资格时间；反例重置资格。超过60秒仍不足时显示UNRESOLVED而非NORMAL。OUTAGE在10Hz状态日志中按距最后有效GNSS的时间判定。

局部health要求两个已可用插值端点有效点数≥100、平均绝对平面残差≤0.2m；这是适用规则，不是LIO正确性证明。查询最大跨度0.15秒，允许可用延迟0.25秒；不以未来位姿填洞。

## 修订与保留历史

r01 (`motion_recovery.py`) 只检验短时运动资格。12组合W∈{1,2,5}s、分数限∈{4,9}、资格∈{1,2}s均因正常代价被淘汰。health缺失后额外迟滞造成正常代价，诊断见P4/r01.md。

r02 (`availability_recovery.py`) 只修证据可用性：B6持续运行影子决策，不创建第二滤波器；只有可用短时运动异常或实际GNSS断点才覆盖成熟规则。health或未形成窗口时回共同成熟策略并标记UNRESOLVED。相同12组合，C9(W5s/分数4/资格2s)恢复正常代价，目标收益0.067067m/2.1811%，未达门槛。

r03 (`anchored_recovery.py`) 只增加过去规则验证的原始观测锚。其短时参数固定r02 C9，不再调参。候选锚须是已接入NORMAL/健康/短分数通过且名义NIS≤共同onset的观测，持续5或15秒；保留最新原始z、接收机R及独立LIO天线位置，不把多条观测平均成虚构独立精度。仅实际GNSS断点激活锚检查；隔离和恢复期间冻结。锚分数为

`a = z_now − [z_anchor + a_L,now − a_L,anchor]`

`score_anchor = a_xyᵀ [R_now,xy + R_anchor,xy + growth×(q_time Δt + q_distance Δdistance) I]⁻¹ a_xy`

锚不一致则否决并重置资格；兼容且完成恢复才解除激活，之后才可推广新锚。无已验证锚时短时规则继续并如实记录；health不足时用r02成熟回退，不能声称仍有锚保护。锚限{4,9,16}×持续{5,15}s×Q增长{1,4}为最后12组。不存在r04授权。

## 归因、门槛与边界

主目标是三类事件(连续跳变/30秒失锁正常恢复/30秒失锁+10m持续偏差)的等权事件宏RMSE。最强同代价B6=3.074919m；候选须改善≥3%且≥0.1m、覆盖≥99%、自然路线水平RMSE≤2.589027m。七类事件及自然子集完整保留。人工偏移可能抵消真实接收机误差，不能称现场故障概率。

若r03主缓存通过，固定参数运行无运动(B6轨迹精确复现)、时间资格而不查运动分数、无恢复衰减、无锚(r02轨迹复现)消融；两个保留前端缓存均检验强控制与候选，不在第二缓存再调参。最小收益必须超过两缓存收益的差异，所有失败公开。开发增益不等于独立增益；此前端重放数值变化未解决。

稳定GNSS偏差与间断中积累的LIO漂移可产生相同输入，因此锚只能识别相对不一致，不能证明哪一传感器正确、绝对完整性或所有恢复均安全。原始锚可能带多路径偏差。监测相关性、工程Q/R、固定旋转、未知地理原点的共同初始平移、与参考系统共享AT128都限制结论。

## 来源和最近邻

FAST-LIO2及i2Nav AT128适配、KF-GINS独立B1、KF/NIS/Huber/渐进保护均是已有基础。WinTA-GIL已有窗口运动几何和恢复航向校正；本轮固定旋转，检验SPP位置观测接入。Dual-ACKF已有GNSS bias状态、双自适应CKF与分阶段保护；B6是共同3D KF的局部强控制，不是完整Dual-ACKF复现。保留原始锚及其隔离资格的具体作用需要消融与双缓存证据支持，只可定位为有限应用机制，不能称首次鲁棒融合、首次滑窗或首次恢复管理。相关工作未完整取到的公式明确未核实。

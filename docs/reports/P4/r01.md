# r01 决策卡：否定现有规则，修订证据可用性

问题：B6_C9的持续偏差恢复event RMSE4.9562m仍有空间。
证据：P3 141054205503；r01 driver143431646773 exit0，402.8909s，12主配置、52个配置/场景及独立评价组合全部保留；原始21事件不变。
假设：只新增短时GNSS/LIO天线位移分数控制隔离和渐进重接入，与同Huber、同wait2/15s/15倍保护比较。
最近邻：一致性、资格累计及分阶段R不认定新颖；这里不估计yaw或bias状态。
实现：motion_recovery.py + 独立候选wrapper；B6消融输出精确一致与未来GNSS因果检查exit0。Q/R、初态、缓存、事件不变。

结果：12配置natural RMSE2.66457–2.70216m，全超过共同cap2.589027m，无合格候选。仅诊断用途的最低主要误差C9：target2.987221m vs B6 3.074919m，绝对0.087698m、相对2.852%，仍未达>=0.1m且>=3%；natural2.700023m，不能称有效改进。7类别与全部超时均保留，未选有利场景或打开留出。

逐更新诊断：较短窗口C0/C2等自然数据没有任何短时分数越限，但多拒24–34条GNSS，相对B6的14条，表明额外代价不能归因于发现更多人工异常。原生六次局部health不可用（9242/9741/9747/9748/10152/10211s）把内态留在UNRESOLVED；恢复healthy后缺窗口又触发资格等待，首次差异在9243s：nominalNIS0.2117，B6接受、r01拒绝。不能按单条NIS或真值自动称所有自然拒绝为“错误GNSS”。

稳定偏差的短窗口盲区仍存在，具体人工偏差接收计数由独立revision_diagnostic.json记录；该标签只用于评价，未进入算法。

决定：否定r01为有效改进。r02只修订证据不可用时的迟滞：成熟固定恢复作为连续影子策略；只有已取得的运动异常证据或真实观测空洞启动新增资格。局部health缺失退回成熟策略并明确UNRESOLVED，不把单纯窗口缺失变成新的GNSS故障。暂不加锚，不改Q/R或传感器；同12有限主参数。若正常代价恢复后稳定偏差仍是实际剩余问题，才考虑r03可信锚。候选预算已用1/3、12/36；无科学冻结或正增益。

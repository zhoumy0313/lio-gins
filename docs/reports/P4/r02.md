# r02 决策卡：正常代价恢复，稳定偏差仍未解决

问题及来源：r01有不可用证据迟滞的正常代价，见r01.md和diagnostic144459710262。
假设/唯一修订：保持B6固定恢复为连续影子决策（不创建第二滤波器或更新）；只有足够运动证据异常或实际失锁才启用新增资格。局部health/窗口不可用时回成熟策略并标记UNRESOLVED，不制造GNSS故障。
实现：新增availability_recovery.py；保留r01实现和结果。4项availability因果/影子策略比较exit0，纯旋转非零杆臂集成检查exit0，无虚假平移。

结果：driver144816244929 exit0，12主配置、52配置/场景与独立评价组合全部保留。选中C9：natural2.584656605m（cap2.589027），target3.007852163m vs B6 3.074919162m；改善0.067066999m、2.1811%，不满足>=0.1m且>=3%。部分配置的natural与B6数值完全一致，支持前轮额外代价确来自不可用证据处理；不据此声称全方法有效。

主要事件：短时窗口开始能隔离跳变，却会在稳定偏移期间重新取得资格；实际admission和恢复超时计数见独立诊断。不能用持续一致代替绝对位置正确。七类完整结果不删；人工偏移可能抵消真实GNSS误差，所有方向均报告。

决定：不把r02冻结为有效方法。最终r03只新增持续验证、隔离时不刷新的GNSS/LIO锚，用同位置KF和原始接收机观测检验稳定偏差恢复。以r02最优合格C9固定其W=5s、短时limit4、good2s，不再调这些参数。锚归一化含接收机R和增长的共同Q工程近似；新增锚分数/持续验证时长/增长倍率最多12组合。无外部参考不能保证分辨大LIO漂移与GNSS偏差，必须保留不可辨识边界。

当前2/3修订、24个主配置，无正增益、无科学冻结或留出性能。r03后停止新机制；仅在全门槛、消融和双缓存复核通过时继续P5。

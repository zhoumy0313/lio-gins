# R2 作者决策简报

**问题：GNSS 失锁后恢复可用时，何时接入才能兼顾及时纠正、带偏观测暴露与定位误差？** 已交付完整六页英文审查稿 `paper/versions/r2_r03/main.pdf`，属于 Mode B，带红色 NOT_SUBMISSION_READY。建议先由导师/作者审查为实证案例研究，当前不宜以“独立验证的新方法改进”投稿。

实际贡献是一个可追溯的恢复时效评价协议和完整公平对照：固定 FAST-LIO2 相对运动、同一个外层三维位置 KF、相同接收机 GNSS、初始化和缓存，只改变观测接纳策略。KF-GINS 为独立 GNSS/INS 对照。共19个命名策略、456组方法/缓存/情境配对、1197个固定事件记录；原64项回归加9项指标测试通过，独立复算最大差异4.44e-16m。P-r03 保持 R1 原样，没有新方法修订、没有停车场调参，也没有重复部署旧 Pipeline。

**与 R1 反证的关系：** R1 的 NO_ADDITIONAL_GAIN 及全部旧代码、实验、负结果、论文草稿未改。R2 在知道 R1 结果后提出新评价问题和服务预算；不将新的条件性事实倒写为原无约束聚合误差的胜利。前端两次缓存差异3.6013m RMS、最大9.7876m，原因尚未查明；初始化依赖明确参考初态、参考传感器有重叠，人工注入不是自然故障检测验证。16个building和46个parking注入行反而降低声明初始化条件下的接收机误差，因此“接入注入行数”不是实际错误概率。

**不能说：** 首次运动窗口辅助恢复、普遍优于现有融合算法、自动识别真实多路径、统计显著、已完成独立验证、录用有保证。WinTA-GIL 与 Dual-ACKF 已有相近机制；未在本平台正式复现它们，不能把其论文数字列成同条件 SOTA 对照。本轮新增机制增量与新颖性均未成立。

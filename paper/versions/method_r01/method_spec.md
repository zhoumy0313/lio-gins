# 候选机制与归属

P3已完成；2026-10-11起r01只检验短时运动验证的增量作用。参数表在method_search_protocol.json，任何真实性能前声明12个主配置；候选实现还需合成因果验证。前端、位置KF、Q/R、共同初始化、GNSS输入和21固定事件均不改变。

令a_L为独立LIO补偿到天线的NED位置，z为接收机位置，W为秒数窗口。监测d=(z_t−z_{t−W})−(a_L,t−a_L,t−W)，只用连续可用的过去观测。水平工程分数d_xyᵀ(R_t,xy+R_old,xy+Q_interval,xy)⁻¹d_xy不是新增量测，也不声称校准概率或样本独立。

NORMAL用相同Huber；大创新、失锁或运动不一致启动隔离/验证。至少固定wait2秒且持续通过运动分数规定时长后接入；一旦失败重置资格。恢复R倍率沿用固定B6的15→1有限15秒平方衰减，仅把起点与资格和恢复验证挂钩。不改K、不剪残差、不重置位置、不把差分再次更新。资格不足60秒后标记UNRESOLVED，不显示NORMAL。

已有配准诊断仅作保守适用条件：可用端点有效点数>=100且平均绝对平面残差<=0.2m；否则停用新增运动否决，用同Huber并记录UNRESOLVED。诊断不等于证明LIO准确，两个前端相同输入的米级差异仍需独立报告与复核。

r01无可信锚，稳定偏移可能在短窗口内完全一致，预先登记为盲区。只有实际r01开发证据表明该失败时才执行r02锚机制；不提前写成已解决。

最终候选须超过同代价的成熟强对照，正常水平RMSE统一不超过2.589027m，不能比NIS享有更高代价预算。必要时比较无运动、仅同样时间资格、无恢复衰减与无锚消融；两份LIO缓存固定参数复核后才考虑冻结。当前不主张增益、新颖性或论文可投稿。

FAST-LIO2提供局部状态，KF-GINS为独立B1；3D线性KF、NIS、Huber、渐进恢复均是已有基础。与WinTA-GIL的窗口航向优化不同，本项目固定旋转、仅管理原始SPP位置接入；与Dual-ACKF完整18维bias/双自适应CKF不同，本项目不增加INS偏置或GNSS偏置状态。这些是范围区别，需要消融和最近邻核查才能决定研究增量。
